# 长征·一条路的来处

> 一部沿着真实地理、时间和史料走进去的长征数字学习地图。

项目定位：面向全部群众的非游戏化交互历史地理教育展。

当前状态：**立项前准备包 v1.0**。已有可演示原型，时间线体验改造进行中；仍未进入正式产品开发。

## 已锁定原则

- 第一版主线只讲中央红军（红一方面军）1934 年 10 月至 1935 年 10 月的长征；
- 1936 年三大主力会师作为长征总史尾声，不能与中央红军路线混画成一条线；
- 不做战争游戏、闯关、积分、排行榜、卡牌或伤亡数字刺激化；
- 每个核心节点至少两条权威出处，事实、解释、可视化还原分别标注；
- 路线必须标注“确定 / 约略 / 争议”，不伪装成逐日 GPS；
- 史实公开不等于图片、扫描件、地图和视频可自由复用；
- 中国境内公开地图展示以标准地图与天地图合规体系为基准；
- 默认支持 8-10 分钟导览、自由地图探索和史料证据入口；
- 时间线以真实日期比例呈现，自由探索与导览分别使用 `timelineT` 和 `revealT`；
- 目标无障碍标准为 WCAG 2.2 AA，并提供文字路线与简明/深入双层内容。

## 尚未完成的开工前事项

1. 由历史教师、党史研究者或纪念馆专业人员审核九个单元口径；
2. 对每个节点补齐至少两条可长期访问的权威来源；
3. 确认首批使用的图片、档案扫描和旧地图是否获得书面授权；
4. 向自然资源主管部门咨询交互网页、导出截图和离线包的地图审核边界；
5. 完成一个争议路线段、一个 DEM 剖面和一个离线课堂的技术 Spike；
6. 用纸面或低保真原型完成 5-8 名混合公众测试；
7. 等待 CMIT 2026 正式竞赛指南，确认最终类别和截止时间。

以上门禁未通过前，不进入正式开发。
