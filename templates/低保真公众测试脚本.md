# 低保真公众测试脚本

## 目标

在开发前验证：普通公众能否理解项目范围、三模式、九节点主线、路线精度和史料标签；产品是否被误读为游戏或精确轨迹。

## 样本

5-8 人：

- 2 名普通成年公众；
- 1-2 名中学生或亲子；
- 1-2 名中老年用户；
- 1-2 名有无障碍需求的用户。

使用匿名编号，不记录政治面貌、身份证、电话等无关信息。

## 材料

- 首页三入口纸面稿；
- 九节点时间线；
- 一个完整节点五问卡；
- 一张含确定/约略/争议的地图；
- 事实/解释/可视化还原标签卡；
- 史料入口样稿；
- 文字路线与大字模式样稿。

## 任务

1. 不解释，让用户选择一个入口；
2. 完成 8 分钟导览纸面 walkthrough；
3. 指出这条主线讲的是哪个红军部队和时间范围；
4. 解释为什么路线不是一条预先规划好的直线；
5. 判断三段路线分别是确定、约略还是争议；
6. 在 30 秒内找到一个事实的出处；
7. 判断三句话分别属于事实、解释、可视化还原；
8. 使用大字、文字路线或键盘流程；
9. 回答“你觉得这是游戏吗？哪些画面像真实历史现场？”

## 指标

| 指标 | 目标 |
| --- | ---: |
| 导览完成率 | ≥80% |
| 说清范围、重要性、路线非直线 | ≥70% |
| 模式切换成功率 | ≥85% |
| 30 秒来源发现率 | ≥80% |
| 标签辨识率 | ≥75% |
| 无障碍关键任务 | 100% |
| 认知负荷 1-5 | 平均 ≤3 |

## 观察记录

```text
参与者编号：
使用设备/辅助技术：
入口选择：
最大困惑：
是否误认为游戏：
是否误认为精确GPS：
是否误认为还原图是真实影像：
能否找到来源：
建议：
```

## 决策

- 达标：进入产品规格评审；
- 部分达标：修订信息架构后再测；
- 史实/地图/还原误读严重：停止开发，重新设计表达。
