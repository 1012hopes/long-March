# 版权与授权方案

## 1. 核心判断

史实可公开查询，不等于承载史实的照片、视频、旧地图、扫描件和数据库页面可以直接复制使用。

必须区分：

- 原始作品版权状态；
- 数字化扫描、摄影或数据库版本的版权状态；
- 机构允许查询的范围；
- 机构允许公开传播、改编和比赛展示的范围。

## 2. 来源使用策略

| 来源 | 可以先做什么 | 上线前要求 |
| --- | --- | --- |
| 国家档案局 / 档案平台 | 查目录、申请利用、记录档号 | 遵守保管馆规定，公开发表或复制需确认 |
| 中央党史和文献研究院 | 核验文献、标题、书目和观点 | 官网多处禁止未经书面授权使用，正文/版面图需申请 |
| 国家博物馆 / 军博 / 纪念馆 | 研究展陈与馆藏说明 | 数字影像、展览图和视频逐件授权 |
| 新华网 / 人民网 | 查权威报道和图像线索 | 新闻图片、视频和图表通常需书面许可 |
| 国家公共文化云 | 查公共文化资源 | 按作品标注和授权范围使用，商业用途另询 |
| 国家图书馆及数据库 | 查旧报刊、书目和资料位置 | 禁止批量抓取、再开发和再分发，逐库看许可 |

## 3. 版权红线

- 不把“官网能看”当作“可以下载改编”；
- 不从搜索引擎或社媒保存来源不明图片；
- 不搬运带新华社、人民网、博物馆等权利声明的图片和视频；
- 不批量抓取数据库全文、扫描件或瓦片；
- 不把旧照片默认视为公版；
- 不把公版文件原文与机构制作的高清数字化件混为一体；
- 不用 AI 修复、上色或“动起来”来绕过原素材授权；
- 不把未授权素材打包进可下载离线包。

## 4. 最稳替代方案

拿不到授权时：

- 根据核验过的事实自行绘制信息图；
- 自制路线图、时间轴和海拔剖面；
- 自己拍摄纪念地外景，并遵守场馆拍摄规则；
- 只提供权威页面标题、机构名和可访问链接，不复制图片；
- 使用开放 DEM 派生地形图，并按许可署名；
- 使用抽象纸张、档案编号、等高线和文字排版建立视觉，不虚构“历史照片”。

## 5. 授权台账字段

必须维护 `research/rights-register.csv`，字段包括：

- 资源 ID；
- 来源机构；
- 资源标题；
- 类型；
- 原作者/摄影者/编者；
- 权利主体；
- 原作是否过保护期；
- 数字化件权利主体；
- 获取方式；
- 允许用途；
- 可否下载、改编、商用、二次传播；
- 署名要求；
- 授权文件编号或链接；
- 授权联系人；
- 审批人；
- 风险等级；
- 替代方案；
- 备注。

## 7. 授权邮件最小内容

申请应明确：

- 项目为大学生非商业竞赛/公共教育用途；
- 使用的具体资源与编号；
- 展示渠道、预计访问范围和使用期限；
- 是否裁切、标注、动画化或离线打包；
- 署名位置；
- 是否允许在作品截图、视频、PPT、展板和官网中重复出现；
- 请求书面确认，并保存邮件与附件。
