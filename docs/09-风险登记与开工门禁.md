# 风险登记与开工门禁

## 1. 风险登记

| 风险 | 等级 | 触发信号 | 缓解措施 | 开工阻塞 |
| --- | --- | --- | --- | --- |
| 中央红军线与长征总史混写 | 高 | 吴起镇被写成全部长征唯一终点 | 主线范围声明，1936 尾声独立 | 是 |
| 史实错误或单源结论 | 高 | 关键事实只有一条二级来源 | 每节点至少两条权威来源 + 专业审核 | 是 |
| 路线假精确 | 高 | 细线无精度标签、逐日 GPS 语气 | 确定/约略/争议几何与图例 | 是 |
| 地图合规 | 高 | 非标准边界、无审图号、离线瓦片 | 标准地图/天地图，主管部门咨询 | 是 |
| 图片与扫描件侵权 | 高 | “网上找到的老照片”进入素材包 | 版权台账、书面授权、自制替代 | 是 |
| 历史人物虚构 | 高 | AI 对话、心理旁白、伪引语 | 只引用有出处原文，不做实时人物 AI | 是 |
| 游戏化误读 | 高 | 胜负、分数、最佳路线、伤亡排行 | 非游戏化回看，教育审核 | 是 |
| 全龄口号但不可访问 | 高 | 地图无文字替代、字幕缺失 | WCAG AA、文字路线、多模态测试 | 是 |
| 节点太多导致浅薄 | 中 | 30+ 景点卡片、正文不满来源 | 九单元锁定，每单元五问 | 否 |
| 3D 过度 | 中 | 先做地球飞行、性能差 | 2D 先行，3D 需独立证据 | 否 |
| 网络依赖 | 中 | 无网无法打开地图或内容 | 离线课堂包与降级图 | 是 |
| 竞赛赛道变化 | 中 | 2026 正式指南与 2025 不同 | 发布当天复核类别与材料 | 是 |
| 用户认知负荷 | 中 | 术语多、导览完成率低 | 简明/深入层与前测 | 是 |

## 2. 开工门禁

下列条件全部满足后，才进入正式设计与开发。

### G1 史实门禁

- [ ] 九个教学单元名称、时间和地点完成专业审核；
- [ ] 每节点至少两条权威来源；
- [ ] 强渡大渡河、飞夺泸定桥、懋功会师、吴起镇等易混点有审核说明；
- [ ] 所有数字有口径；
- [ ] 1936 总史尾声与主线分开。

### G2 版权门禁

- [ ] 首批媒体逐项进入授权台账；
- [ ] 至少一个完整节点的媒体全部为可用/已授权/自制；
- [ ] 未授权素材有替代方案；
- [ ] 作品图、视频、PPT、展板和离线包的授权范围明确。

### G3 地图门禁

- [ ] 底图来源和坐标系确定；
- [ ] 标准地图和天地图使用条款确认；
- [ ] 路线精度三层 Spike 通过；
- [ ] 地图审核问题清单提交给专业窗口；
- [ ] 不打包未授权在线瓦片。

### G4 教育门禁

- [ ] 五问模板完成一个节点样稿；
- [ ] 事实/解释/还原标签通过测试；
- [ ] 5-8 名混合公众低保真测试达标；
- [ ] 无障碍关键任务完成率 100%；
- [ ] 没有被用户误读为游戏或真实现场影像。

### G5 技术门禁

- [ ] 天地图接入 Spike；
- [ ] DEM 对比 Spike；
- [ ] 离线课堂 Spike；
- [ ] 手机和投影 Spike；
- [ ] 性能预算可达；
- [ ] 所有核心功能不依赖云端模型。

### G6 竞赛门禁

- [ ] 2026 正式指南已下载归档；
- [ ] 项目负责人已按每周一例行检查、发布后 24 小时触发检查执行并留记录；
- [ ] 类别、截止日期、材料和展板规格已确认；
- [ ] 校赛联系人、指导教师和推荐流程已落实；
- [ ] 作品未在其他比赛获奖；
- [ ] AI 工具使用与原创声明边界已确认。

## 3. 开工决策

- `GO`：六类门禁全部通过；
- `CONDITIONAL GO`：只剩不影响第一节点原型的外部事项，且有明确日期；
- `NO GO`：史实、地图、版权任一高风险门禁未通过。

第一版禁止以“边做边补史实/授权”为理由绕过门禁。
