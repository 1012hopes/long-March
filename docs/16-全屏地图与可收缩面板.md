# 全屏地图与可收缩面板

## 1. 设计决定

产品工作区采用：

> 全屏地图作为持续存在的空间底层，信息面板作为可收缩、可替换的覆盖层。

地图不因面板开合重新创建、重新定位或改变当前缩放。面板覆盖区域只影响控件安全边距，不影响地图数据状态。

## 2. 桌面面板

### 左侧：时间与节点

三态：

- `expanded`：约 280px，显示时间轴、九节点和日期；
- `rail`：约 64px，显示年份刻度和当前节点编号；
- `closed`：只保留“展开时间与节点”按钮。

时间状态采用 `timelineT` / `revealT` 分离：左侧脊柱和底部拖动条读写 `timelineT`，导览和自动播放才推进 `revealT`。自由探索里拖动时间不会把后续路线藏掉；导览里时间拖动被锁定，停靠点负责同步当前阅读位置。

### 右侧：节点 / 史料

两种内容共享一个 380-440px 抽屉：

- 节点学习；
- 史料与出处。

切换内容时抽屉位置不变。抽屉完全关闭后，地图占满右侧。

### 底部：地形与条件

三态：

- `summary`：约 56px，显示当前段海拔、日期和精度；
- `half`：约 220-280px，显示海拔剖面和地形说明；
- `closed`：保留展开按钮。

### 顶部浮动控制

- 返回首页；
- 导览 / 自由地图 / 史料；
- 图层；
- 简明 / 深入；
- 大字 / 文字路线 / 减少动态；
- 专注地图；
- 浏览器全屏（可选，不作为核心依赖）。

## 3. 手机面板

地图始终全屏。

顶部：当前模式、当前节点和菜单。  
底部：统一抽屉承载节点、史料、地形和图例。

抽屉三态：

- `peek`：显示节点名和核心问题；
- `half`：阅读简明层；
- `full`：深入层、史料和无障碍文字路线。

不同面板不能同时打开，避免遮住地图和造成焦点混乱。

导览模式下手机不显示独立的时间线抽屉入口，避免同一屏出现两套时间语义；当前站信息由导览卡与节点抽屉承载。

## 4. 状态模型

```ts
type WorkspacePanels = {
  left: 'expanded' | 'rail' | 'closed'
  right: 'node' | 'sources' | 'closed'
  bottom: 'summary' | 'half' | 'closed'
  focusMap: boolean
  mobileSheet: 'peek' | 'half' | 'full'
  mobileView: 'node' | 'sources' | 'terrain' | 'legend'
}
```

进入专注地图时保存旧状态；退出后恢复。

## 5. 交互规则

- 每个面板都有明确文字按钮，不依赖 hover；
- `Escape` 关闭当前最上层面板；
- 面板关闭后焦点回到触发按钮；
- 键盘可以循环访问面板内部；
- 手机抽屉支持按钮和拖拽，但按钮是必需的无障碍替代；
- 面板状态可保存在本地，但不保存个人信息；
- 切换节点时右侧面板内容更新，但不强制展开；
- 连续拖动时间指针时不反复触发镜头飞行，只有点击节点、切换导览停靠点或跨越路线段时才自动调整镜头；
- 点击地图空白不自动关闭重要史料，避免误触；
- 投影模式默认左窄栏、右关闭、底部摘要；
- 导览模式默认左窄栏、右节点面板、底部摘要；
- 自由地图模式默认左展开、右关闭、底部摘要。

## 6. 地图安全区域

地图控件根据可见面板计算安全边距：

```text
top = topBarHeight + 16
left = leftPanelVisibleWidth + 16
right = rightPanelVisibleWidth + 16
bottom = bottomPanelVisibleHeight + 16
```

比例尺、图例、缩放、定位和当前节点标签不能被面板遮挡。

地图 `fit()` 和节点定位使用安全区域，不直接用整个浏览器矩形。

## 7. 验收标准

- 关闭全部面板后地图填满视口；
- 面板开合不改变地图中心、缩放和当前时间；
- 专注地图退出后恢复之前状态；
- 1440×900 和 1920×1080 下地图面积不少于可视区域 70%；
- 390×844 下关闭抽屉时地图面积接近 100%；
- 手机只允许一个主抽屉打开；
- 无 hover 也能完成全部操作；
- 键盘、触摸和屏幕阅读器均可展开/关闭面板；
- 面板打开后地图关键控件不被遮挡；
- 文字路线不依赖地图和面板动画。
- `prefers-reduced-motion` 下所有平滑滚动、飞行和脉冲动画都要即时降级，但层级与可读性不变。
