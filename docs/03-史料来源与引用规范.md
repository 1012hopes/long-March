# 史料来源与引用规范

## 1. 来源优先级

### A 级：首选

- 中央档案馆 / 国家档案局；
- 中央党史和文献研究院；
- 经正式出版的党史基本著作、文献选编、年谱；
- 国家博物馆、中国人民革命军事博物馆与官方纪念馆馆藏说明；
- 国家机关正式文件。

### B 级：可用于交叉核验

- 共产党员网、中国共产党新闻网、人民网党史、新华网党史专题；
- 省级党史研究部门、地方档案馆、纪念馆和政府官网；
- 权威学术期刊与出版社研究著作。

### C 级：只作线索

- 单一回忆录、口述、地方文史材料；
- 新闻转述；
- 旅游宣传页；
- 未标注来源的展板和短视频。

C 级不能单独支撑关键事实，百科和自媒体不能作为产品主引用。

## 2. 每项内容的引用要求

### 时间、地点、路线

- 至少两条独立权威来源；
- 记录来源发布日期、原文日期口径和访问日期；
- 不同来源不一致时标“来源有争议”；
- 路线必须附精度等级和推理说明。

### 数字

- 写明统计对象、时间范围、来源和是否为约数；
- “二万五千里”等历史概称不转换成假精确公里数；
- 伤亡与人数不作视觉刺激或排行榜。

### 引语

- 必须可定位到书名、卷册、页码、档案号或权威网页；
- 不根据事件“合理想象”人物说话；
- 回忆录引语注明作者、成文时间和回忆性质。

### 图片、旧地图和档案扫描

- 史实来源和素材版权分开记录；
- 记录原作者、权利主体、数字化件权利主体、授权范围和署名要求；
- 没有权利链不得进入正式资源包。

## 3. 内容卡必须保存的字段

```text
内容ID
节点ID
内容类型（事实/解释/还原）
正文
来源ID列表
审核人
审核日期
争议状态
简明层/深入层
最后修改记录
```

## 4. 来源条目字段

```text
来源ID
标题
作者/机构
来源类型
出版或发布日期
出版社/馆藏机构
卷册/页码/档案号
URL
访问日期
可靠性等级
可引用范围
版权状态
备注
```

## 5. 摘录纪律

- 默认用自己的语言概述，不大段搬运；
- 必须逐字引用时使用引号并标出处；
- 不从多个来源拼成一个貌似原始的历史人物引语；
- 不把研究文章结论删去限制条件后写成事实；
- 不以 AI 总结代替阅读原始来源；
- AI 可以帮助整理，但所有进入产品的内容必须由人核对来源原文。

## 7. 节点内容审核工作流

1. 研究者填写来源台账；
2. 内容编辑写简明层与深入层；
3. 第二人逐句做“主张—来源”核对；
4. 历史专业审核人签字；
5. 版权负责人确认所有媒体状态；
6. 地图负责人确认路线精度与来源；
7. 只有全部通过，节点状态才从 `research` 变为 `approved`。
