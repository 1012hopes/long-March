# 视觉风格规范

## 1. 风格名称

**国家档案测绘桌 × 历史地理图志**

核心体验：观众像站在一张正在被研究、标注和核验的历史测绘桌前。地图、时间、地形和史料不是装饰，而是互相证明的证据。

关键词：

- 庄重；
- 克制；
- 准确；
- 纸面；
- 测绘；
- 档案；
- 地形；
- 批注；
- 公众可读；
- 当代数字展陈。

不使用：

- 红金党建模板；
- 宣传栏式大标题；
- 战争游戏 HUD；
- 军事雷达与作战指挥大屏；
- 血条、兵力、攻击箭头和胜负反馈；
- 烧焦纸边、血迹、弹孔等戏剧化做旧；
- 大面积五角星、光芒和金色浮雕；
- AI 紫色渐变、玻璃拟态和普通科技蓝大屏。

## 2. 视觉母题

### 历史地图是底层

主画面始终以地图、等高线、河流和路线为核心，不用人物插画抢夺地图主体。

### 史料像证据卡

史料使用档案编号、来源机构、形成日期、引用范围和权利状态构成卡片。不要把史料做成装饰相册。

### 红线是历史线索

红色只用于中央红军主路线、关键转折和当前导览位置。不能把整个界面全部染红。

### 批注代表解释

解释、疑问和争议使用铅笔线、括号、圈注、边注和连线。批注必须服务理解，不能制造凌乱的“手账感”。

## 3. 色彩系统

### 基础色

| Token | 色值 | 用途 |
| --- | --- | --- |
| Paper | `#F2EEE4` | 主背景、纸张 |
| Paper Light | `#FCFAF5` | 内容卡和地图面板 |
| Ink | `#1C1D1B` | 主文字和关键边界 |
| Ink Soft | `#565952` | 次级文字 |
| Archive Line | `#C9C1B3` | 网格、卡片线、档案分隔 |
| Terrain | `#727963` | 山地、等高线、自然条件 |
| River | `#647D8F` | 河流、水系、渡口 |
| Route Red | `#A6322B` | 中央红军路线和当前节点 |
| Route Red Soft | `#D8A39D` | 约略走廊和历史范围 |
| Evidence Blue | `#315E78` | 事实、档案、来源 |
| Interpretation Ochre | `#9A6B2F` | 历史解释 |
| Reconstruction Orange | `#B85E32` | 可视化还原 |
| Disputed Violet | `#765B78` | 来源争议与候选路线 |

### 使用比例

- 65% 米白与纸色；
- 20% 墨黑与灰线；
- 8% 地形绿灰与河流蓝灰；
- 5% 路线红；
- 2% 标签色。

红色不能超过页面视觉面积约 10%，否则会变成模板化红色专题。

## 4. 路线视觉编码

### 确定路线

- 实线；
- Route Red；
- 线宽 3-4px；
- 节点使用实心圆和文字标签；
- 同时配“史料明确”文字，不只靠颜色。

### 约略路线

- 半透明走廊；
- Route Red Soft；
- 内部可有一条细示意中心线；
- 固定标签“约略范围，不代表逐日精确轨迹”。

### 争议路线

- 2-3 条紫灰候选虚线；
- 同属一个争议组；
- 点击后并列显示各自来源；
- 不预设其中一条为正确答案。

### 当前导览段

- 路线红略加深；
- 节点外围出现轻微定位环；
- 不使用闪烁、爆炸或发光拖尾。

## 5. 标签视觉

| 标签 | 颜色 | 图形 | 语气 |
| --- | --- | --- | --- |
| 事实 | Evidence Blue | 实线矩形 | 已有来源支持 |
| 解释 | Interpretation Ochre | 侧边批注 | 基于史实的分析 |
| 可视化还原 | Reconstruction Orange | 虚线框 | 数字示意，不是现场记录 |
| 来源有争议 | Disputed Violet | 双线或分叉符号 | 存在不同版本 |
| 权利待确认 | 灰黑 | 锁形文字标记 | 不能进入正式媒体包 |

标签必须同时有文字，不使用纯色圆点代替含义。

## 6. 字体系统

### 中文标题

建议：思源宋体 / Noto Serif CJK SC，使用免费可商用版本并保存许可证。

适用：项目名、章节名、历史节点标题。

原因：本项目属于档案、历史地图和公共教育语境，宋体用于少量标题具有明确编辑和文献依据，不用于大段正文。

### 中文正文

建议：思源黑体 / Noto Sans CJK SC。

适用：导览、说明、按钮、无障碍文本。

### 数字与档案编号

建议：霞鹜等宽 / IBM Plex Mono / 系统等宽字体。

适用：日期、坐标、档案号、路线段 ID、来源编号。

### 字号基线

- 正文：16-18px；
- 深入阅读：18px，行高 1.75；
- 地图标签：投影模式不小于 18px；
- 节点标题：24-32px；
- 项目主标题：桌面 44-64px，手机 34-42px；
- 支持至少 200% 放大。

## 7. 桌面与投影布局风格

整体像一张铺满桌面的历史测绘图。地图是全屏底层，档案、时间轴和地形解释以可收缩工作面板覆盖在其上：

```text
┌────────────────────────────────────────────┐
│ 顶部浮动控制：模式 / 图层 / 无障碍 / 专注地图 │
│ ┌──────┐                         ┌────────┐ │
│ │时间与│       全 屏 历 史 地 图   │节点学习│ │
│ │节点  │                         │史料抽屉│ │
│ └──────┘                         └────────┘ │
│ ┌────────────────────────────────────────┐ │
│ │ 地形 / 海拔 / 日期 / 路线精度（可上拉） │ │
│ └────────────────────────────────────────┘ │
└────────────────────────────────────────────┘
```

视觉规则：

- 地图始终覆盖整个可视区域；
- 面板是漂浮在地图上的档案夹和测绘工具，不切割地图为固定列；
- 面板打开时地图保持连续，不重新缩放或跳动；
- 左侧时间面板支持展开、窄栏、收起三态；
- 右侧节点面板和史料面板使用同一抽屉位置，避免同时堆叠；
- 底部地形面板默认只显示摘要条，需要时上拉；
- “专注地图”模式收起所有解释面板，投影时只留下路线、图例和当前节点；
- 面板使用细线、轻纸层和半透明实底，不用玻璃拟态和厚重阴影；
- 当前节点卡像放在地图旁的研究记录；
- 史料卡可以有折角、档案编号和来源章，但不模拟污渍；
- 投影模式增加字号和对比，去掉细微纸纹；
- 不在大屏上做密集后台表格。

## 8. 手机布局风格

- 地图默认铺满整个手机屏幕；
- 顶部使用紧凑浮动栏，不占固定大标题空间；
- 当前节点与学习内容放在底部可上拉档案夹中；
- 底部抽屉三态：摘要约 72px、半屏、近全屏；
- 用户下拉抽屉即可回到完整地图；
- 横向时间轴像测绘尺，不像游戏进度条；
- 一次只展开一个主面板：节点、史料或地形；
- 史料、地形和来源使用同一底部抽屉容器的不同视图；
- 路线文字模式与地图并列为一级入口；
- 不把桌面三栏缩小塞进手机。

## 8.1 面板状态视觉

### 展开

- 档案纸实底；
- 清晰标题、关闭和收缩按钮；
- 地图相应区域添加轻微遮罩以保持文字对比；
- 不模糊地图，不使用玻璃拟态。

### 窄栏 / 摘要

- 只显示当前日期、节点名称、一个核心问题或海拔摘要；
- 保留明显的展开手柄和文字标签；
- 不能只用小图标表示功能。

### 完全收起

- 仅保留 44×44px 以上的恢复按钮；
- 恢复按钮固定在不会遮挡路线、比例尺和图例的位置；
- 键盘焦点回到恢复按钮；
- 屏幕阅读器能读出“展开时间轴”“展开节点说明”等完整名称。

### 专注地图

- 所有面板同时收起；
- 路线、图例、比例尺、当前节点和来源状态仍可见；
- 退出专注模式后恢复此前各面板状态，而不是全部强制展开。

## 9. 动效语言

允许的动效：

- 地图平移和缩放；
- 路线沿时间顺序缓慢显现；
- 等高线与海拔剖面同步；
- 档案卡打开；
- 批注线从来源连接到内容主张；
- 争议路线并列展开；
- 当前节点定位环轻微出现。

不允许：

- 自动快速飞地图；
- 镜头轰炸、爆炸、枪声和警报；
- 人物肖像“活过来”；
- 长时间视差、摇晃和闪烁；
- 强制自动播放；
- 用动效掩盖没有来源的历史细节。

全部动效支持减少动态效果。关闭动效后，信息和关系仍完整。

## 10. 图片与场景还原风格

### 获得授权的历史照片

- 保持原始比例；
- 不擅自上色、补帧、换背景；
- 可加中性边框、来源和说明；
- 不裁掉原始语境中的关键内容。

### 自制插图

- 使用地形剖面、轮廓、物件、地图和文献结构；
- 不制作无出处的具体战斗场面；
- 不虚构人物表情和心理；
- 需要人物时优先使用剪影、队伍尺度示意和已授权肖像。

### 可视化还原

统一放置明显标签：

> 可视化还原：依据史料、地图和地形数据制作，不等同于历史现场影像。

## 11. 纸张与纹理

纸纹只作为低对比背景，透明度 2%-5%。

可以使用：

- 细纤维纹理；
- 测绘网格；
- 等高线；
- 档案打字机编号；
- 铅笔批注；
- 淡色盖章。

不要使用：

- 重度泛黄；
- 烧焦边缘；
- 血迹；
- 墨水泼溅；
- 过度毛边；
- 为“年代感”主动降低可读性。

## 12. 声音方向

声音不是必须，但可作为第二阶段：

- 低音量环境底声；
- 纸张、翻页、铅笔和电报机等可解释音效；
- 地形环境声必须标“声音设计”，不能假装现场录音；
- 旁白庄重、平实，不采用影视预告片腔；
- 默认不自动播放；
- 所有音频有文字稿和静音选项。

## 13. 视觉验收标准

- 第一眼能看出地图是主体；
- 不会被误认成战争游戏或军事指挥系统；
- 不会被误认成传统红金宣传网页；
- 确定、约略、争议路线在不看颜色时仍能区分；
- 事实、解释、还原标签辨识率 ≥75%；
- 地图缩到手机仍能读当前节点；
- 1080p 投影后正文和地图标签清晰；
- 减少动效后信息不缺失；
- 没有授权的图片不会以灰色占位图进入最终视觉；
- 视觉设计不会把路线示意伪装成精确史实。

## 14. 第一轮视觉样张

正式 UI 开发前只制作三张静态样张：

1. 桌面总地图沙盘；
2. 手机节点详情与底部档案夹；
3. “遵义会议—通道/黎平/猴场”事实、解释、还原和史料证据页。

三张样张需通过：历史审核、地图合规初审、无障碍对比检查和 5 人公众视觉辨识测试。未通过前不铺开九节点界面。
