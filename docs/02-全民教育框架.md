# 全民教育框架

## 1. 受众不是一个人群

“全部群众”必须拆成可实现的用户类型：

| 用户 | 基础需求 | 主要风险 |
| --- | --- | --- |
| 低预备知识公众 | 先理解长征是什么、为什么走、路线为何变化 | 术语和地名过载 |
| 中学生与亲子 | 与历史、思政学习衔接，形成时空与史料意识 | 变成背题或打卡 |
| 中老年公众 | 大字号、慢节奏、重复观看、语音辅助 | 交互过密、地图难用 |
| 带问题的学习者 | 快速查人物、会议、路线、出处和争议 | 来源藏太深 |
| 有无障碍需求者 | 与其他人平等获得核心内容 | 只有形式无障碍，没有内容无障碍 |

产品不设儿童专版；第一版简明层应让约 12 岁以上具备基础阅读能力的公众独立理解。更低年龄建议亲子共看，避免用幼儿化语言处理严肃历史。

## 2. 同核三层模式

三个入口使用同一内容和来源体系，不是三个独立产品。

### 跟我走一遍

- 默认入口；
- 8-10 分钟；
- 九个教学单元压缩为 6-8 个导览停靠点；
- 每站只讲一个核心问题；
- 用户可暂停、跳过、放大文字和切换语音；
- 不限时、不评分。

### 自己查地图

- 按路线、时间、地点、地形和主题自由探索；
- 单次 3-20 分钟；
- 地图始终提供“文字路线”替代；
- 用户可从任意节点回到主导览。

### 查史料与出处

- 按节点、人物、文献类型和机构查找；
- 每个节点在 30 秒内能找到来源；
- 展示来源类型、出处、权利状态与摘录范围；
- 争议内容并列呈现版本，不能替用户抹平。

## 3. 每节点固定五问

1. **这里发生了什么？** 只写可确认事实。
2. **为什么发生在这里、这个时候？** 解释地理、时间、补给、政治和军事背景。
3. **当事人怎么知道、怎么决定？** 引入地图、电报、档案、回忆和情报条件。
4. **这件事后来产生了什么影响？** 连接后续路线和历史进程。
5. **依据是什么，还有哪些解释空间？** 展示出处、证据强弱和版本差异。

## 4. 内容分层

### 简明层

- 90-140 字；
- 阅读 20-35 秒；
- 包含时间、地点、事件和一个关键意义；
- 用于导览、地图节点和投影讲解。

### 深入层

- 260-420 字；
- 阅读 1-2 分钟；
- 包含背景、过程、影响和来源提示；
- 用于自由探索详情。

### 史料抽屉

- 每条来源说明 40-80 字；
- 每节点 2-5 条；
- 包括档案、文献、回忆录、旧地图、照片、研究和馆藏信息；
- 不把整篇他人文章复制进产品。

## 5. 标签制度

### 事实

有明确来源支持的时间、地点、人物、行动、原文和数据。必须可追溯到具体出处。

### 解释

基于事实的因果说明、历史意义和研究观点。必须说明解释依据，存在多种解释时不得写成唯一事实。

### 可视化还原

路线中心线、走廊、地形、场景、声音与动画的数字表达。固定提示：

> 依据史料、地图与地形数据制作的数字示意，不等同于现场影像或逐日精确轨迹。

### 来源有争议

不同权威来源在路线、日期、数字或细节上存在差异。

### 版本待比对

已有线索但尚未完成多源交叉核验，不能进入默认导览正文。

## 6. 非游戏化学习回看

可用：

- 一句话复述：这一节点最重要的变化是什么？
- 证据配对：哪个史料能支持哪项事实？
- 路线判断：哪段表述更符合当时已知条件？
- 标签分类：某句话是事实、解释还是可视化还原？
- 开放反思：为什么不能只用一条红线理解长征？

不用：

- 分数、排名、连击、徽章；
- 答错锁定内容；
- “你改变了历史”的模拟；
- 胜负、伤亡排行榜和军事成就游戏化。

## 7. 无障碍基线

- WCAG 2.2 AA；
- 正文默认不小于 16px，支持至少 200% 放大；
- 地图、路线和精度不能只用颜色区分；
- 所有地图有文字摘要和文字路线；
- 图片、旧地图和还原画面有替代文本；
- 视频有字幕，音频有同步文本；
- 不自动播放，不使用闪烁，不设限时操作；
- 全流程键盘可操作；
- 投影模式支持 1280×720 和 1920×1080；
- 手机覆盖 360×640 至 430×932；
- 在开发早期邀请有无障碍需求者参与测试。

## 8. 前期用户测试

样本 5-8 人，至少覆盖普通公众、中学生/亲子、中老年和无障碍需求用户。

| 指标 | 门槛 |
| --- | ---: |
| 8-10 分钟导览完成率 | ≥80% |
| 能说出“是什么、为什么重要、路线非直线” | ≥70% |
| 导览切换到地图或史料入口成功率 | ≥85% |
| 30 秒找到节点来源 | ≥80% |
| 事实/解释/还原辨识率 | ≥75% |
| 放大字号、字幕、文字路线、键盘导航关键任务 | 100% 可完成 |
| 主观认知负荷 1-5 分 | 平均 ≤3 |

定性必记：哪些内容被误认为真实影像、唯一解释、精确轨迹或游戏任务。
