# 前期制作排期与角色分工

这不是开发排期，而是开工前准备排期。建议 3 周完成，未完成则顺延开发。

## Week 1：口径与史料

### 目标

- 中央红军主线与九个单元定稿；
- 每节点至少两条来源；
- 完成一个节点的五问样稿；
- 建立来源与版权台账。

### 验收

- 历史审核人对范围和易错表述签字；
- 所有来源可访问或有书目信息；
- 没有无出处引语和假精确路线；
- 至少一个节点达到 `approved`。

## Week 2：地图、版权与低保真

### 目标

- 路线三种精度 Spike；
- 天地图与坐标系 Spike；
- DEM 对比；
- 首批媒体授权申请；
- 导览、地图、史料入口纸面原型。

### 验收

- 5 人能解释确定/约略/争议；
- 地图合规问题形成书面咨询材料；
- 一个节点完全使用自制或已授权素材；
- 手机/投影低保真流程完整。

## Week 3：公众前测与立项评审

### 目标

- 5-8 名混合公众测试；
- 无障碍关键任务测试；
- 修订内容层级和模式入口；
- 2026 CMIT 规则复核；
- 完成 GO / NO GO 评审。

### 验收

- 关键指标达到 `02-全民教育框架.md` 门槛；
- 六类开工门禁有状态和负责人；
- 仍未解决的高风险项有明确阻塞结论；
- 用户、指导教师和审核人共同确认是否立项。

## 建议角色

| 角色 | 责任 | 最少人员 |
| --- | --- | ---: |
| 项目负责人 / 信息架构 | 范围、用户、交付、决策记录 | 1 |
| 党史/历史内容审核 | 节点、表述、来源、争议 | 1-2 |
| 史料与版权负责人 | 来源、授权、台账、署名 | 1 |
| GIS / 数据负责人 | 底图、路线、精度、DEM、合规 | 1 |
| UX / 无障碍负责人 | 导览、分层阅读、公众测试 | 1 |
| 视觉设计 | 地图、史料、标签和展陈系统 | 1 |
| 前端工程 | Spike 阶段只做技术验证 | 1 |

## 任务、周次与 Owner

| 任务 | 周次 | Owner | 复核/协作 |
| --- | --- | --- | --- |
| 九节点来源补齐与五问样稿 | W1 | 史料与版权负责人 | 历史审核人 |
| 中央红军/总史口径审核 | W1 | 历史审核人 | 项目负责人 |
| 版权台账与首批授权申请 | W1-W2 | 史料与版权负责人 | 指导教师 |
| 路线段台账与精度 Spike | W2 | GIS / 数据负责人 | 历史审核人 |
| 天地图、DEM、离线 Spike | W2 | GIS / 数据 + 前端工程 | 项目负责人 |
| 三模式纸面原型 | W2 | UX / 无障碍负责人 | 信息架构、视觉 |
| 5-8 人公众前测 | W3 | UX / 无障碍负责人 | 项目负责人 |
| 2026 CMIT 规则复核 | 每周一；发布后24h | 项目负责人 | 指导教师、校赛联系人 |
| GO / NO GO 评审 | W3 末 | 项目负责人 | 全角色签字 |

一人可以兼任多个角色，但“内容写作者”和“史实复核者”不能由同一个人独立闭环。

## 用户需要线下推进的事项

1. 联系本校历史、马克思主义学院或相关教师担任内容审核/指导教师；
2. 联系至少一个长征沿线纪念馆，询问资料与授权；
3. 联系学校教务处确认 CMIT 校赛联系人；
4. 联系自然资源部门地图审核咨询窗口；
5. 招募混合用户测试样本；
6. 保存所有授权邮件、会议纪要和审核签字。
