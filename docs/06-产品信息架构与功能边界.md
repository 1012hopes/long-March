# 产品信息架构与功能边界

## 1. 首页入口

三个入口：

- **跟我走一遍**：8-10 分钟主导览；
- **自己查地图**：自由探索九个教学单元；
- **查史料与出处**：按节点与资源类型查看依据。

首页同时展示：

- 中央红军主线范围声明；
- “非游戏化历史教育展”说明；
- 简明 / 深入阅读切换；
- 大字、字幕、语音和文字路线入口；
- 地图和数字还原免责声明。

进入任一学习模式后，主工作区采用“全屏地图 + 可收缩覆盖面板”，不再使用固定三栏挤压地图。

## 2. 导览模式

固定节奏：

1. 总览：主线范围与时间；
2. 路线推进；
3. 每站核心问题；
4. 地形或史料视图；
5. 事实 / 解释 / 还原标签；
6. 一句学习回看；
7. 下一站。

导览不自动播放，不强制听完音频，不用进度奖励。

## 3. 自由地图模式

图层：

- 中央红军主路线；
- 确定 / 约略 / 争议路线；
- 时间轴；
- 地形与海拔；
- 河流、山地和渡口；
- 事件节点；
- 史料可用性；
- 1936 总史尾声。

操作：

- 点击或键盘选择节点；
- 拖动时间轴，不改变史实，只过滤时段；
- 切换路线精度图例；
- 打开文字路线；
- 从地图进入节点详情和史料。

时间线模型：

- `timelineT` 表示历史阅读位置，左侧时间轴和底部拖动条共用它；
- `revealT` 表示路线与节点的显影进度，只在导览或自动播放时推进；
- 自由探索里可以单独移动 `timelineT`，但不会隐藏后续路线；
- 导览里 `timelineT` 与当前停靠点同步，拖动被锁定。

### 全屏地图工作区

- 地图占满浏览器主视口；
- 顶部只保留项目名、模式、无障碍和全屏/专注按钮；
- 左侧时间与节点面板可在“展开 / 窄栏 / 完全收起”之间切换；
- 右侧节点学习面板以抽屉覆盖地图，可展开或完全收起；
- 底部地形、海拔和时间解释面板可从 56px 摘要条上拉到约 240px；
- 史料入口使用独立抽屉，与节点面板不同时占据大面积；
- “专注地图”一次收起全部面板，仅保留地图、图例和恢复按钮；
- 面板覆盖地图而不是改变地图画布尺寸，防止路线和当前节点在开合时跳动；
- 地图控件根据面板状态自动避让，不能被抽屉遮住。

### 动效与导览节奏

- 时间指针、节点卡片和底部摘要的过渡控制在 160-220ms；
- 导览路线显影约 900-1200ms，地图镜头约 1200-1600ms；
- 连续拖动时间轴时不反复抢镜头，只有点击节点、切换导览停靠点或跨段时才移动镜头；
- `prefers-reduced-motion` 下取消平滑滚动、飞行和脉冲，只保留即时状态切换。

## 4. 节点详情

固定顺序：

- 标题、时间、地点；
- 简明层；
- 核心教育问题；
- 五问展开；
- 地形 / 路线 / 时间视图；
- 事实、解释、可视化还原标签；
- 史料抽屉；
- 非游戏化学习回看；
- 上一站 / 下一站 / 返回地图。

## 5. 史料入口

筛选：节点、资源类型、机构、年代、权利状态、来源等级。

每条显示：

- 标题；
- 作者/机构；
- 出版或形成时间；
- 来源类型；
- 引用信息；
- 权利与可用状态；
- 原始链接或申请利用说明；
- 该来源支持的内容主张。

没有授权的图片只显示书目和文字说明，不展示缩略图复制件。

## 6. 不做的功能

- 玩家选择“最佳路线”或改写历史；
- 战役胜负模拟；
- 人物实时 AI 对话；
- 伤亡积分、排行榜、徽章；
- 开放用户上传地图标注；
- 社区、评论和 UGC；
- 全线 3D 漫游；
- 未授权的历史照片 AI 修复与动画；
- 依赖云端模型才能完成的现场主流程；
- 大而全后台管理平台。

## 7. 内容管理边界

第一版内容可由版本化 JSON / Markdown 构建，不必先做后台。需要满足：

- Schema 校验；
- 来源 ID 必须存在；
- 默认正文不能包含未批准内容；
- 未授权媒体不能进入构建；
- 争议内容必须有标签；
- 路线必须有精度和来源；
- 内容变更有审核记录。

只有真实运营需要出现后，才评估编辑后台。

## 8. 首版演示主链路

五分钟竞赛演示只展示：

1. 一句话价值；
2. 主路线和范围口径；
3. 进入一个代表节点；
4. 时间、地形、路线和史料联动；
5. 展示“确定 / 约略 / 争议”；
6. 展示事实 / 解释 / 可视化还原；
7. 打开来源；
8. 切到文字路线和离线模式。

不在五分钟里展示九个节点全部内容。
