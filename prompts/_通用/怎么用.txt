怎么用（四步）
================

1. 从平台可用的模型里任选一款。
     gpt-image-2.6-flare-4k
     gpt-image-2.6-sunburst-4k
   生成水平 360° 的等距圆柱全景。平台支持时选择 4K、2:1，目标为 4096×2048。

2. 复制对应站点的「提示词.txt」。有负向框时，把 _通用/负向提示词.txt
   粘到负向框。只有一个输入框时，在提示词末尾加上「避免出现以下内容」
   和负向词。

3. 按「备注.txt」里的「最容易假的地方」选图。有多张候选时逐张检查。
     · 地平线不在画面正中   → 弃（一转人就往天上飘）
     · 人超过画面高度 1/5   → 弃（走近就是一堵墙）
     · 接缝两边接不上       → 弃（别硬修）

4. 按「备注.txt」里的目录归档原图，保留实际文件格式。用备注里的命令
   处理，4096×2048 的 JPEG 成品会写到 app/public/experience/real/img/wide/，同名成品会被覆盖。
   对于无需裁边的原图，--crop 0 会保留底部。
   脚本同时生成两张检查图。
     .tmp-pano/<输出名>-seam.png   接缝条（最后 260px 和最前 260px 并排）
     .tmp-pano/<输出名>-grid.png   坐标网格（用来标人物和史实点）
   换图时按新网格复核 app/public/experience/real/space.js 的人物和史实点坐标。


几条通用提醒
------------

· 骨架那六句别删。它们是「真实感」的全部来源：
    侧身背影看不清脸 / 六米以外占高 1/6 / 胶片灰雾低饱和 /
    地平线正中 / 左右能接 / 自然光不 HDR

· 源图宽于 2:1 时，脚本会从右边裁掉超出的部分，选图时留意右缘的内容。

· 野外用 --corner 0 0，避免天空出现暗带。四枚银元、半条被子和彝海护旗
  是室内场景，沿用备注里的默认压角。

· node-02q 不用另外出图，它跟 node-02 共用 xiangjiang360.jpg，
  只是站的位置和朝向不同。

· 优先重出泸定桥（node-07）。现有底图含现代游客和设施，选图时按
  research/scene-evidence/node-07.md 核对桥面、人物姿态和时代细节。

· 视频：即梦的图生视频只做 5 秒，适合给站内补「微动」，
  不适合做行军段（行军段要连续九十秒以上，仍走现有实时渲染 + 录制）。
